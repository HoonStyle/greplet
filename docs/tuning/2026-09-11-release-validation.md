## 범위와 동결

평가군은 실제 기존 사용 기록에서 얻은 24개 고유 질문이다. 로컬 벤치와 smoke 실행은 제외했고, 중복 및 기존 gold와 정확히 같은 질문도 제외했다. 새 질문을 작성하지 않았으며, 익명 ID만 공개한다.

gold는 순위를 보기 전에 소스·인덱스 근거로 동결했다. 22개는 채점 가능했고 U011·U023은 정답 직접 근거가 부족해 채점 불가로 남겼다. 두 사례도 24개 전체 실행에는 포함했지만 적중과 MRR의 분모에는 넣지 않았다. 동결 전 순위 검색은 0회였고, 정책은 T10으로 고정해 재튜닝하지 않았다.

정확도는 24개 × 3모드 × 2범위 × 3회 × 2버전으로 864회를 실행했다. `original`은 질문의 원래 범위, `all`은 전체 범위다. topN은 5이며 캐시를 우회했다. 공개 JSON의 순위 0은 gold가 top 5 밖이라는 뜻이고 null은 채점 불가다.

| 범위 | 모드 | 기준 적중@5 / MRR@5 | 후보 적중@5 / MRR@5 |
|---|---|---:|---:|
| original | FTS | 12 / 0.39924 | 12 / 0.39924 |
| original | vector | 16 / 0.45076 | 16 / 0.45076 |
| original | hybrid | 16 / 0.46136 | **18 / 0.46894** |
| all | FTS | 6 / 0.14545 | 6 / 0.14545 |
| all | vector | 9 / 0.21364 | 9 / 0.21364 |
| all | hybrid | 4 / 0.08333 | 4 / 0.08333 |

원래 범위 hybrid의 신규 적중은 U019·U022이며 기존 적중 손실은 없다. 전체 범위의 hybrid 결과는 그대로다. 전체 범위 점수가 낮은 이유를 이 정책의 회귀나 개선으로 일반화하지 않는다.

적중을 유지한 사례 중 U002는 2→3위, U005는 1→2위, U006은 2→5위, U007·U020은 1→2위로 내려갔다. 지정 워크스페이스 hybrid 지연 중앙값은 56.81→58.47ms, p95는 69.70→70.99ms였다.

## 부하와 API 점검

동시성 검사는 1·4·8 동시 요청에서 원래·전체 범위를 교대하고 3회 반복했다. 같은 동결 인덱스와 검색 동작을 쓰는 캐시 우회 loopback HTTP 하네스이며 운영 API 지연 측정이 아니다.

| 동시성 | 기준 p95 ms | 후보 p95 ms | 오류 / 경고 / 혼선 |
|---:|---:|---:|---:|
| 1 | 152.206 | 150.131 | 0 / 0 / 0 |
| 4 | 254.709 | 260.531 | 0 / 0 / 0 |
| 8 | 480.528 | 483.328 | 0 / 0 / 0 |

별도의 운영 API 확인은 216회였고, 192회는 캐시 응답이었다. 오류·경고·응답 혼선은 모두 0이다. 이 API 결과는 캐시 우회 동시성 지연 수치와 섞어 비교하지 않는다.

## 소스 사전 점검과 한계

U001의 한 문서는 검색 시작 전 현재 원문 해시가 인덱스 생성 당시와 달랐다. 현재 문서가 해당 주제를 포함하는 것은 확인했지만, 이 평가는 현재 문서의 사실 정확도가 아니라 **동결 인덱스 버전에서의 순위**를 평가한다. 나머지 20개 접근 가능한 원문 해시는 일치했고, 검증 중에는 소스·인덱스 해시 안정성이 유지됐다.

이 검증은 검색 순위·반복 안정성·요청 결과만 다룬다. 사용자 답변 품질, 계획, 보안성, 최신 원문에 대한 사실성은 평가하지 않았다. 원시 질문, 대상, 함수, 프로젝트, 경로, 원시 행, 응답 내용과 사용자 환경 정보는 공개 자료에 포함하지 않는다.

적중은 미리 지정한 관련 근거 청크 중 하나 이상이 상위 5개에 있는지를 뜻한다. 질문의 모든 의도를 충족했다는 평가나 모든 관련 문서를 전수 라벨링한 평가는 아니다. 키워드 단서가 많은 기존 사용 로그여서 T07의 새 자연어 100문항과 같은 분포로 해석하지 않는다.
