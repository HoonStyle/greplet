# T07 — 새 자연어 100문항 확대 검증

2026-09-11 · 구현 커밋 **`898e559`** · 상태: **실측 완료, 추가 튜닝 없음**.

후속 기록: 아래 보류군 15문항은 T07 시점에는 미실행이었으며, [T10 융합 비교](2026-09-11-vector-prefix.md)에서 후보를 고정한 뒤 처음 평가했다. 현재는 미사용 보류군이 아니다.

## 결론

**4:1 가중 RRF는 동일 비중 RRF보다 개선됐지만, 자연어에서는 벡터 단독보다 낮았다.** 새 질문 100개에서 기존 hybrid 39개, 가중 hybrid 57개, vector 64개가 목표를 상위 5개에 포함했다. 따라서 4:1을 기존 RRF의 개선으로 볼 근거는 늘었지만, 자연어 검색의 최선이라고 일반화할 수 없다.

이전 8문항 검증에서는 적중 손실이 없었으나, 확대 평가에서는 **20개 신규 적중과 2개 적중 손실**이 확인됐다. 이번 결과에 맞춰 가중치를 추가 조정하지 않았다. 운영 4:1 설정을 유지하며, 다음 자연어 정책 비교를 위한 결과로 남긴다.

## 표본 구성과 측정 조건

- 새 질문 **115개**를 원문에 근거해 작성했다. **100개를 실제 검색**하고, **15개는 검색하지 않은 보류군**으로 남겼다. 실측 N은 100이며, 미실행 보류군 15개는 실행 횟수·적중률 분모에 포함하지 않았다.
- 실측 대상은 **서로 다른 함수 100개, 소스 파일 91개, 워크스페이스 5개**다. 이전 48문항의 목표 함수와 중복이 없음을 확인했다.
- 독립 작성 작업 두 개와 주 작업에서 질문을 만들었다. 정답 심볼·원문 근거 줄·인덱스 포함 여부를 확인했으며, 질문 작성 중 검색 순위를 보지 않았다.
- 원본 질문에는 정확한 클래스·메서드명을 넣지 않았다. 함수·프로젝트·파일·질문 원문·익명 대응표는 로컬에만 보관하고, 공개 결과는 E001 등의 사례 ID와 W1 등의 워크스페이스 ID를 사용한다.
- 3개 작성 집합에서 각각 5문항을 보류하되, 같은 소스 파일이 실측군과 보류군을 넘나들지 않게 분리했다. 분할 시드·질문 해시와 **1:1 / 4:1** 가중치를 검색 전에 고정했다.
- **100문항 × FTS/vector/hybrid 3모드 × 5회 × 2버전 = 3,000회** 실제 검색했다. 예열 제외, topN=5, 결과 캐시 우회, 모드 순환 및 버전 실행 순서 교대 조건이다.
- 모든 정답 청크가 인덱스에 존재하고, 원본 파일 해시가 인덱스 기록과 같음을 확인했다. 측정 전후 대상 워크스페이스의 매니페스트 해시도 동일했다.

이번 100개는 **코드의 한국어 자연어 검색** 확대 평가다. 이전 코드·PDF 혼합 40개와 분포가 다르므로 수치를 직접 이어 붙여 정확도가 변했다고 해석하지 않는다. 소스에서 작성한 알려진 목표 검색 평가이며, 무작위 실제 사용자 요청이나 모든 관련 정답을 라벨링한 벤치마크는 아니다.

## N과 불확실성

반복 5회를 독립 정답 표본으로 세지 않는다. **N=100**이며 함수들이 같은 파일·프로젝트의 문맥을 공유할 수 있다.

- 적중률의 Wilson 95% 구간: 1:1 **30.0~48.8%**, 4:1 **47.2~66.3%**.
- 동일 질문의 적중 변화에 대한 파일 단위 paired bootstrap 10,000회: 차이의 95% 구간 **+9.7~+26.5%p**.
- 독립 문항 쌍을 가정한 exact McNemar p값은 약 **0.00012**다. 파일·프로젝트 의존성과 소스 기반 표본 선정 편향까지 제거한 증거는 아니다.

이 수치들은 작성한 평가군 내 개선의 불확실성을 설명하며, 서비스 전체 정확도의 신뢰구간으로 해석하지 않는다. 이전에 보류한 15개는 여전히 미실행 상태다. 이번 100개는 결과를 확인했으므로 이후 튜닝에 사용하면 새 검증군으로 간주하지 않는다.
