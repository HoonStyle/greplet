# 실제 마이그레이션 파일럿 기록

상태: **미실행**. 자동 합성 테스트 결과를 실제 마이그레이션 결과로 대체하지 않는다.

## 준비

- 제품·고객별 레거시 5개, 현재 코드, 스펙의 워크스페이스 slug와 소스 스냅샷을 기록한다.
- 변경 전 Greplet 기준 커밋은 `220fbdd5a82948bb89f9423a80293f7789d69eb1`이다. 개선 버전은 파일럿 실행 시 실제 커밋 SHA로 고정한다.
- 서로 다른 버전의 Greplet은 별도 인덱스 데이터 디렉터리를 사용한다. 실제 프로젝트 파일은 비교 실행 동안 변경하지 않는다.
- Serena 버전·프로젝트 설정, 모델 ID·effort, 프롬프트, 출력 한도와 임베딩 모드를 동일하게 유지한다.
- 정답 근거는 실행 전에 사람이 원문으로 확인한다. 검색 실패나 빈 결과를 기능 부재로 판단하지 않는다.

## 실행별 기록 (과제당 각 조건 3회)

각 실행에 `task_id`, `condition`(기존/개선), `repeat`, Greplet·Serena·소스 버전, 모델·effort, 필수 근거 누락 수, 출처 오인용 수, 오래된 근거 정상 취급 수, 도구 호출 수, 재조회 수, 입력·출력·캐시 토큰, 소요 시간을 남긴다. 과제별 조건 실행 순서는 번갈아 수행하고 새 대화에서 시작한다. 요금 정보가 없는 실행의 비용은 비워 두며 토큰 수와 비용을 혼용하지 않는다.

호출 예:

```bash
node greplet.mjs evidence-search "대상 기능" --all > evidence-search.json
# targets[].hits[].evidenceRef 중 확인할 객체 하나를 evidence-ref.json 에 저장한다.
node greplet.mjs evidence-get --ref-file evidence-ref.json
```

## 판정

고정된 5과제에서 필수 근거 누락·출처 오인용·오래된 근거 정상 취급이 모두 0이어야 한다. 모델 오류, 검색 후보 누락, 스펙 추출 누락, 도구 연결 오류를 구분해 기록한다. 토큰 절감은 참고 지표이며 품질 조건을 대신하지 않는다. 실패가 하나라도 있으면 파일럿은 미완료로 유지하고 해당 원인을 수정한 뒤 영향 과제를 다시 수행한다.
